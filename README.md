# grid-pulse

Explore the future of web audio with Cyber-Pulse Audio Engine 2.0—a lightweight, self-contained HTML/JS cybernetic spectrum and 3D audio visualizer. Open it instantly in any browser to experience real-time signal processing, customizable thermal color palettes, and interactive matrix lightshows without installing any software or server infrastructure. 🚀

### 🚀 Quick Start Guide

1. **Open the App:** Click any of the links above to open directly on GitHub Pages, or double-click a downloaded HTML file to open locally.
2. **Launch Audio:** Click the **"Start Audio Stream"** button at the top left.
3. **Choose Your Source:**
   * **Built-in Synth (Default):** Generates live, punchy electronic patterns and synth sweeps automatically.
   * **Microphone / System Audio:** Tap into your mic or capture browser tabs/music streaming directly.
