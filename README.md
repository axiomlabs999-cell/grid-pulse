# grid-pulse
Explore the future of web audio with Cyber-Pulse Audio Engine 2 lightweight, self-contained HTML/JS cybernetic spectrum and 3D audio visualizer. Open it instantly in any browser to experience real-time signal processing, customizable thermal color palettes, and interactive matrix lightshows without installing any software or server infrastructure.
🚀 Quick Start Guide

    Open the App: Double-click the downloaded HTML file (index.html) to open it instantly in any modern web browser (Google Chrome, Microsoft Edge, Brave, or Firefox).

    Launch Audio: Click the "Start Audio Stream" button at the top left.

    Choose Your Source:

        Built-in Synth (Default): Generates live, punchy electronic patterns and synth sweeps automatically so you can see the visualizer react immediately without needing an external audio file.

        Microphone / System Audio: Tap into your mic or capture browser tabs/music streaming directly.

        File Upload: Drag and drop or upload your own MP3, WAV, or audio files to visualize your own beats!

✨ Key Features & Modes

    Multiple Visualizer Modes: Switch between layouts on the fly:

        2D Matrix Grid: A responsive, glowing grid of pads that light up dynamically with the audio frequencies.

        3D Hologram Grid: An immersive, interactive 3D cube matrix that you can click and drag around with your mouse.

        Floating Spectrum Bars: Classic vertical audio spectrum analyzer bars.

        Radial Burst: A circular, pulsing visualizer ring.

    Thermal & Neon Color Themes: Customize the aesthetic with preset color palettes ranging from Thermal (Green-to-Hot Red Peak) to Cyber Neon, Vaporwave, and Matrix Cyber.

    Real-time Signal Controls: Fine-tune the visuals using the interactive sliders:

        Gain Sensitivity: Boost or lower the audio reactivity.

        FFT Smoothing: Adjust how fluid or sharp the frequency response reacts.

        Peak Fall Decay: Control how fast the peak lights drop down.

💡 Pro-Tips

    Interactive Pads: In the 2D Matrix mode, you can actually click or tap the individual grid pads to trigger interactive audio blips!

    Zero Install: Because everything is self-contained in a single file, you don't need to install Python, Node.js, or any external drivers. Just save and play!
